# Kopi — Manual testing checklist

- [ ] Copy plain text on Android, paste on Mac in less than 1 s
- [ ] Copy plain text on Mac, paste on Android in less than 1 s
- [ ] Copy a card number on Android, paste masked on Mac in less than 1 s
- [ ] Copy a card number on Mac, paste masked on Android in less than 1 s
- [ ] Take a screenshot on Android, paste the image on Mac
- [ ] Copy an image on Mac, check it arrives on Android
- [ ] Restart the phone, check sync resumes without re-pairing
- [ ] Leave the app 3 h in the background, check sync still works
- [ ] Switch to the phone hotspot, check sync reconnects
- [ ] Unpair and pair again, check sync works
